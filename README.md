# VexInclinator

**Zero-fee all-in-one Solana wallet cleaner.**

Reclaim **100%** of locked SOL from empty token accounts. No cuts. Non-custodial.

## Features
- Close empty SPL / Token-2022 accounts → full rent back
- Dust / spam token scanner
- Excess rent awareness (post-2026 SIMD-0437)
- Batch close
- Multi-wallet scan (paste addresses)
- Open source

## How it works
Connect Phantom → Scan → Approve close txs. Your keys never leave the wallet.
